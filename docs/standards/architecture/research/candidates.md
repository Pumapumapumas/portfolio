# Action candidates — the running list

The durable home for research action candidates. `synthesis.md` is rewritten every cycle; **this is not**. A rejected candidate stays visible so it is not re-proposed.

## The rule

> **Research creates and appends. Planning dispositions.**

- Research adds candidates with a **stable ID** (`C-NNN`), never reused, never renumbered.
- Two orthogonal flags — **do not collapse them**:

| Flag | Values | Who sets it |
|---|---|---|
| `decision` | `ship` · `requires review` · `reject` · **blank = not yet triaged** | planning triage |
| `status` | `open` · `closed` | a later process (the item lands in a plan / the build completes it) |

- **Nobody deletes a row.** Both flags carry their reasoning in the Note.

Full mechanics: CDF memory model — `claude-dot-files/docs/guide/memory-model.md`.
